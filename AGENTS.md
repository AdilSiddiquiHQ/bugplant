# Notes for AI agents working in this repository

`bugplant` exists to answer one question: **did the tests the agent just wrote actually test anything?**

Because this tool measures whether other agents' code and tests are real, this codebase must hold itself to the highest standard of verification. Do not guess, do not fabricate numbers, and never weaken assertions to pass tests.

## Commands

```bash
npm test        # Full unit + end-to-end + README transcript verification
npm run check   # Quick check of package, claims, and asset invariants
npm run demo    # Build throwaway repo and generate demo transcript
npm run gifs    # Regenerate assets/demo.gif and assets/score.gif (macOS only)
```

Always run `npm test` before concluding your work.

## Core Architecture

- **Tokenize (`lib/tokenize.js`):** Lightweight JavaScript/TypeScript tokenizer. Distinguishes code from strings, comments, template literals, and regexes.
- **Mutate (`lib/mutate.js`):** Six mutation families (`relational`, `arithmetic`, `logical`, `boolean`, `literal`, `increment`). Seeded sampling using `mulberry32`.
- **Git diff (`lib/gitdiff.js`):** Parses `git diff -U0 <base>` to identify added lines. Only added lines in source files are candidates.
- **Graph (`lib/graph.js`):** Parses relative imports (`import`, `export ... from`, `require`, `import()`) to identify which test files observe a modified file. Falls back to full test suite if unresolvable.
- **Runner (`lib/runner.js`):** Spawns child test runners. Strips `NODE_TEST_CONTEXT` from child environments to avoid false passes in nested `node --test` runs. Classifies runs into `pass`, `fail`, `timeout`, and `invalid`.
- **Engine (`lib/engine.js`):** Runs baseline test gate. Iterates through sampled mutants, applies mutation, executes tests, restores original source in `finally` block and on process signals (`SIGINT`, `SIGTERM`).
- **Report (`lib/report.js`):** Formats terminal and JSON output. Calculates `score = killed / (killed + survived)`.

## Hard Invariants

1. **Zero runtime & development dependencies:** `package.json` must have `dependencies: {}` and `devDependencies: {}`. Enforced by `test/package.test.js`.
2. **Never claim an unmeasured number:** If a number or score is in `README.md`, it must be backed by a test or match the real demo output.
3. **README demo block is byte-pinned:** The block between `<!-- demo:start -->` and `<!-- demo:end -->` is generated by `scripts/demo.mjs` and verified byte-for-byte in `test/readme.test.js`.
4. **Action YAML has no inline script logic:** `action.yml` must use `using: composite` and call `scripts/bugplant.sh` directly. `scripts/bugplant.sh` must start with `set -euo pipefail`.
5. **Exact badge count:** `README.md` must have exactly 8 badges. Enforced by `test/package.test.js`.
6. **Exit code contract:**
   - `0`: Success (score >= min-score).
   - `1`: Threshold failed (score < min-score).
   - `2`: Error / unexecutable (usage error, missing git ref, failing baseline, invalid config).
7. **Score equation:** `score = killed / (killed + survived)`. Discarded/syntax invalid mutants never inflate the score. Timed-out mutants count as killed with a timeout indicator.
8. **Restore safety:** Never leave a file mutated on disk. Always restore in `finally` and ensure signal traps are active.
